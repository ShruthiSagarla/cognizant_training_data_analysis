# cognizant_training_data_analysis
Interactive student performance analysis using python, pandas, seaborn, visualization, and Streamlit.

## Project overview
This is a data analytics project that analyzes student performance, marks, and overall academic trends.In this project python and popular data analysis libraries like clean,analyze and visualize the data .

# Objectives
- Calculate average and total marks
- Identify high and low performing students
- visualize academic trends
- Generate useful insights from student data

# Technologies used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- jupyter notebook

# visualizations
- Bar Charts
- Pie Charts
- Histograms
